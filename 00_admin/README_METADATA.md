# Administrative metadata

`source_log.xlsx` is the source-data register. Its worksheets record provider, source file, sample coverage, units, and processing notes for deposited series.

`variable.xlsx` is the variable dictionary. Its worksheets document variable names, source mapping, transformation rules, and manuscript-facing variables.

These workbooks are preserved source metadata. Review them directly when a file-level definition is needed; this note does not replace or alter their contents.
