# v2.0.0 release notes

Approved version; prepared for the authorized GitHub main push. No tagged v2.0.0 Release or new Zenodo archive is created by this operation. This package supports **Renminbi-denominated oil-price movements and inflation dynamics across China's price system** as a new PLOS ONE manuscript.

The revised main design uses stationary local projections with p=2 and h=0–12 for RMB oil-cost log movements and calendar-month changes in year-on-year Fuel/PPI/CPI inflation. It replaces the earlier principal DLM/ARDL framing. Retained historical DLM evidence is labelled in S3 and is not the current primary model.

The final package contains seven redesigned main figures in TIFF/PNG/SVG/EPS, six main-table CSV/XLSX pairs, 18 Supporting Tables, three Supporting Figures, 56 Python sources and frozen statistical outputs. The 2026-10-15 drawing revision used existing frozen inputs and a shared visual module. No models, bootstrap or SI were recomputed. One packaging-only verifier reports checkout integrity and current gates; scientific estimation programs and saved numerical results remain unchanged. Earlier actual verification of 39 OLS/HAC equations is inherited; full numerical/rendering execution is not newly claimed.

MIT is implemented for author-owned revised software and its associated documentation. CC BY 4.0 is implemented for author-original figures, tables and shareable statistical outputs. Third-party observations remain outside those grants; only the attributed public-domain EXCHUS extract is bundled. The 2015–2016 Customs closure covers 24 exact official month matches / 48 quantities-and-amounts comparisons; the other 110 months were not newly compared.

The latest Word already contains the corrected Table 2 Fuel h=12 interval, 0.3072[0.1118, 0.5484]. Its Data Availability heading still requires the final text in docs/DATA_AVAILABILITY_FINAL.md. MathType objects are retained; the manuscript was not rewritten by this preparation.
