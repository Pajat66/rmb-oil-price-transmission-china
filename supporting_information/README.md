# Supporting Information

The fixed v2.0.0 release contains 21 numbered attachments in [journal_submission](../journal_submission): 18 XLSX Supporting Tables and three TIFF Supporting Figures, indexed by the [v2.0.0 captions](../metadata/captions.json) and [sheet mapping](../metadata/si_file_mapping.csv). The main branch additionally includes [S1 Data](../journal_submission/S1_Data.xlsx) for separate PLOS ONE Supporting Information submission, bringing the current total to 22 files. The archive and validation descriptions below refer to the original 21 table/figure attachments; S1 Data is listed separately in the [current repository guide](../README.md#repository-guide).

archive/ retains SUPPORTING_INFORMATION_TABLES.xlsx forS1–S17, S18_LP_lag_order_sensitivity.xlsx and36 table-sheet CSVs. Archive and split attachments package the same overlapping scientific evidence, not independent datasets.

S3 retains5 historical specification/lag-selection/residual-diagnostic sheets526 data rows. Its current caption is substantively consistent. No new bounds/ECM results are appended. S18 retains8 sheets762 formulas/caches, BH/Holm disagreements, significant extra-lag tests and negative sensitivity evidence.

All 21 files are below10MB. SI figures are original300dpi RGB LZW TIFFs. Workbooks were copied without re-saving or recalculation; all44 selected sheets' values, types, formats and formula caches match original archives. Native Excel runtime validation remains unperformed.

Excel absPath local-directory metadata was removed from the17 splitS1–S17 files and their archive. All other OOXML parts, including worksheet values/formulas/caches, styles, shared strings and table definitions, remain byte-identical. Whole-file hashes changed only for this documented privacy transformation.
